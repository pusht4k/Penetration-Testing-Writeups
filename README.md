# Penetration Testing Writeups

This repository contains 100 writeups for Hack The Box and OffSec Proving Grounds machines I completed while preparing for the CPTS and OSCP certifications.

Special thanks to [TJ Null's OSCP Preparation List](https://docs.google.com/spreadsheets/u/1/d/1dwSMIAPIam0PuRBkCiDI88pU3yzrqqHkDtBngUHNCw8/htmlview), which I closely followed throughout my preparation. The list helped me identify weaknesses in my methodology, improve my approach to penetration testing and gain hands-on experience with a wide range of vulnerabilities and exploitation techniques. This preparation contributed to my success in both certification exams, particularly the OSCP, which I completed in approximately five hours.

Each writeup follows a consistent structure, covering enumeration, initial access, privilege escalation and security findings with recommended remediation measures. I chose this format to practice not only identifying and exploiting vulnerabilities but also documenting them clearly and providing actionable remediation recommendations. Reporting is an essential part of penetration testing, and I wanted these labs to help me develop that skill alongside my technical abilities. I also created an [OSCP Cheat Sheet](https://github.com/pusht4k/OSCP-CHEAT-SHEET) to organize useful commands, tools and techniques throughout my preparation.

I hope these writeups can serve as a useful learning resource for others preparing for penetration testing certifications. I plan to continue updating this repository as I complete additional labs and CTF challenges.
